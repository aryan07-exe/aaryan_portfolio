# Aaryan Sahu — React Portfolio

A dark, minimal AI-engineering portfolio built with React, Vite, Tailwind CSS, Three.js, GSAP and Lenis.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (normally `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

## Stack

- React + Vite
- Tailwind CSS 3
- Three.js (custom particle / wireframe visual)
- GSAP + ScrollTrigger
- Lenis smooth scrolling
- Lucide React icons

## Customize before publishing

1. Check all role dates, performance metrics and project descriptions.
2. Replace project GitHub links with the exact repositories.
3. Add the correct DocMind and CLI Agent live-demo URLs if available.
4. Update phone/email if you do not want them public.
5. Replace the placeholder project illustrations with your own screenshots if desired.
6. Confirm the employer-approved wording for professional work before publishing.

## Notes

The 3D hero and about visuals are generated procedurally with Three.js, so no external image service or API key is required. The included project illustrations are local SVG assets.
